One local list, form and set of instruments, dressed three ways. Compare color, spacing and framing while the content and controls stay the same.

Apply .style(.default), .style(.opencode) or .style(.btop) to any view and its descendants. Customize colors, spacing, treatments and surfaces with immutable replacements.

Descendants inherit the complete style; a nearer .style(...) overrides it. Native component modifiers remain specific overrides. Applications own breakpoints, column widths, navigation and data. The main catalog currently offers default, light and btop captures; this page compares default, opencode and btop.

Visual references: OpenCode themes and btop. ChioStyle.opencode uses warm accents, leading panel/input edges, roomier inputs and padded searchable list rows. ChioStyle.btop places group titles in compact outlines. These are visual interpretations, not integrations.
